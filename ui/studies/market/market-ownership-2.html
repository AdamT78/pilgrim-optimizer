Ownership without spending the tile's width

Indulgences is blue's in every strip, so the catalogue's widest name is inside the mark every time. Library is red's, Bank white's, Mint yellow's and donated. Every mark carries a black keyline, which is what lets white be a seat colour on parchment.

Crown — the upper edges only

The band you liked, kept, but only across the three edges above the waist. The name's width is set by the two LOWER slopes, so a band up here costs the tile nothing — Indulgences sits at its full size with all 86.4 units still under it.

Disc in the header

A player disc, which is what the alms table and the piety track already use for a player — as against a cube, which is an acolyte. It shares the top row with the round, and the two centre as a pair, so neither is ever off-axis.

The round box, in the seat colour

No new object at all: the box that is already there takes the owner as its outline, keyed in black so white still reads. Costs nothing anywhere, but ties two facts to one mark.

Foot bar

A short rule at the tile's foot, under the name. Nothing about it scales with the name, so no word can ever collide with it.

Corner wedge

The hex's top-right corner cut off and filled. The quietest of the five, and the only one that stays legible when a tile is half-covered.

The round box no longer greys on a donated tile: a building still woke on the round it woke on, and the grey field says the rest. Only the name and the word Donated go grey with the fill.
